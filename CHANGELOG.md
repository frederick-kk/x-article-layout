# Changelog / 更新记录

## 0.1.0 — 2026-11-24

### English

- Initial public source package with English and Chinese Skill instructions and onboarding.
- Portable helpers for Markdown preparation, explicit cover discovery, native-table insertion, save/reopen verification and cover-body integrity checks.
- MIT license, privacy-aware release checks and packaging, contribution guidance, and an offline CI definition.
- Windows offline validation: 45 Python tests and 17 Node tests passed on Python 3.10.9 / 3.13.5 and Node.js 22.21. GitHub-hosted CI and new users' live X accounts remain separate verification steps.

### 简体中文

- 首个公开源码包，提供完整中英文 Skill 与首次配置引导。
- 辅助脚本支持跨环境的 Markdown 准备、显式封面发现、原生表格插入、保存重开验证和补封面前后正文核对。
- 增加 MIT 许可证、隐私发布检查与打包、贡献说明及离线 CI 定义。
- Windows 离线验收：Python 3.10.9 / 3.13.5、Node.js 22.21 下，45 项 Python 测试和 17 项 Node 测试通过。GitHub 托管 CI 与新用户真实 X 账号仍须分别验收。
