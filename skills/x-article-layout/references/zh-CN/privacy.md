# 运行资料与隐私

[English](../en/privacy.md) | [简体中文](privacy.md)

公开分发的是通用说明、脚本和合成测试，不包括任何人的已登录浏览器、账号配置、文章或草稿。本 Skill 不需要用户交出 X 密码、Cookie、API token 或验证码；登录和验证在其本机 EgoLite 内完成。

## 本地运行会产生什么

计划与验收资料可能包含完整未发布原文、原稿绝对路径、账号、草稿 URL/ID、表格、图片地址、媒体指纹和截图。封面提示词也可能揭示文章主题。这些都是用户的运行资料，不是公共示例。

运行目录、封面输出、临时轮次、浏览器快照和日志默认放在 Vault、Skill 安装目录及待公开仓库之外。只记录恢复和验收所需字段；网络观察仅提取保存状态，不保存请求头、Cookie、令牌或完整网络事件。

## 分享与排错

- 分享 Skill 时只打包源代码、通用参考说明、依赖声明及合成测试。
- 不打包运行目录、output、文章计划、快照、截图、封面原件/元数据、.env、本地图像配置、浏览器数据、虚拟环境、__pycache__ 和测试缓存。
- 提交问题时先用虚构文章或最小合成样本复现；确需真实证据时遮去账号、草稿 ID、私密正文、路径和媒体地址，只分享必要片段。
- .gitignore 只能防止通常的误加入，不能清除已跟踪文件或 Git 历史。公开前检查实际待发布文件和压缩包内容；曾提交的敏感数据需单独处理历史与凭据。

本地隐私检查通过只能证明本次检查范围内未发现相关信息，不能替代用户对其文章公开范围和素材授权的判断。草稿写入与公开发布是两件事；本 Skill 始终止于草稿。
